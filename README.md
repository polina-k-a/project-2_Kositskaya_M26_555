# Primitive DB

Primitive DB -- проект на Python, реализующий простую консольную базу данных.

## Технологический стек

- Тип приложения: CLI (консольное приложение)
- Язык программирования: Python 3.14
- Управление проектом и зависимостями: uv
- Ввод команд: prompt, shlex
- Хранение метаданных: JSON
- Хранение данных таблиц: JSON
- Вывод таблиц: PrettyTable
- Проверка качества кода: Ruff
- Контроль версий: Git

## Установка

```powershell
uv sync
```

## Запуск

```powershell
uv run database
```

Также поддерживается команда `uv run project`.

## Управление таблицами

Программа позволяет создавать таблицы, просматривать список существующих таблиц и удалять таблицы. Информация об их структуре сохраняется в файле `db_meta.json`.

### Доступные команды

| Команда | Описание |
|---|---|
| `create_table <имя_таблицы> <столбец1:тип> ...` | Создать таблицу с указанными столбцами |
| `list_tables` | Вывести список существующих таблиц |
| `drop_table <имя_таблицы>` | Удалить таблицу |
| `help` | Показать справку по командам |
| `exit` | Завершить работу программы |

При создании таблицы автоматически добавляется первый столбец `ID:int`. Поддерживаются типы данных `int`, `str` и `bool`.

### Пример использования

Создание таблицы:

```text
>>>Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool
```

Просмотр списка таблиц:

```text
>>>Введите команду: list_tables
- users
```

Попытка повторного создания таблицы:

```text
>>>Введите команду: create_table users name:str
Ошибка: Таблица "users" уже существует.
```

Удаление таблицы:

```text
>>>Введите команду: drop_table users
Таблица "users" успешно удалена.
```

Просмотр списка после удаления:

```text
>>>Введите команду: list_tables
База данных пуста. Таблицы отсутствуют.
```

Завершение работы:

```text
>>>Введите команду: exit
Выход из программы...
```

## CRUD-операции

Программа поддерживает операции добавления, просмотра, изменения и удаления записей в таблицах.

Данные каждой таблицы хранятся в отдельном JSON-файле в директории `data/`. Например, записи таблицы `users` сохраняются в `data/users.json`.

Каждая запись имеет автоматически генерируемый идентификатор `ID`. При добавлении записи указывать значение `ID` не нужно. Все остальные поля обязательны.

### Доступные команды

| Команда | Описание |
|---|---|
| `insert into <имя_таблицы> values (<значение1>, ...)` | Добавить запись в таблицу |
| `select from <имя_таблицы>` | Вывести все записи таблицы |
| `select from <имя_таблицы> where <столбец> = <значение>` | Вывести записи по условию |
| `update <имя_таблицы> set <столбец> = <значение> where <столбец> = <значение>` | Обновить записи по условию |
| `delete from <имя_таблицы> where <столбец> = <значение>` | Удалить записи по условию |
| `delete from <имя_таблицы>` | Удалить все записи таблицы |
| `info <имя_таблицы>` | Вывести структуру таблицы и количество записей |

Строковые значения указываются в двойных кавычках. Поддерживаются типы `int`, `str` и `bool`. Для вывода записей используется библиотека `PrettyTable`.

### Пример использования

Создание таблицы:

```text
>>>Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool
```

Добавление записи:

```text
>>>Введите команду: insert into users values ("Sergei", 28, true)
Запись с ID=1 успешно добавлена в таблицу "users".
```

Просмотр записей по условию:

```text
>>>Введите команду: select from users where age = 28
+----+--------+-----+-----------+
| ID |  name  | age | is_active |
+----+--------+-----+-----------+
| 1  | Sergei |  28 |    True   |
+----+--------+-----+-----------+
```

Обновление записи:

```text
>>>Введите команду: update users set age = 29 where name = "Sergei"
Запись с ID=1 в таблице "users" успешно обновлена.
```

Удаление записи:

```text
>>>Введите команду: delete from users where ID = 1
Запись с ID=1 успешно удалена из таблицы "users".
```

Информация о таблице:

```text
>>>Введите команду: info users
Таблица: users
Столбцы: ID:int, name:str, age:int, is_active:bool
Количество записей: 0
```

## Декораторы и кэширование

В проекте реализованы декораторы и замыкание для улучшения надёжности и удобства работы с базой данных.

### Обработка ошибок

Декоратор `handle_db_errors` централизованно обрабатывает исключения `FileNotFoundError`, `KeyError`, `ValueError` и другие непредвиденные ошибки. Вместо завершения программы с трассировкой стека выводится сообщение об ошибке.

### Подтверждение удаления

Декоратор `confirm_action(action_name)` применяется к операциям `drop_table` и `delete`.

Перед удалением программа запрашивает подтверждение:

```text
Вы уверены, что хотите выполнить "удаление таблицы"? [y/n]:
```

Операция выполняется только при ответе `y`. При любом другом ответе удаление отменяется.

### Измерение времени

Декоратор `log_time` измеряет время выполнения операций `insert` и `select` с помощью `time.monotonic()`.

Пример вывода:

```text
Функция select выполнилась за 0.001 секунд
```

### Кэширование запросов

Функция `create_cacher()` создаёт замыкание, которое хранит результаты запросов в словаре.

Операция `select` использует кэш при повторных запросах с одинаковыми данными и условиями. После успешного изменения данных кэш очищается, чтобы не возвращать устаревшие результаты.
